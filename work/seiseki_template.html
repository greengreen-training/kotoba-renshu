利用者ごとの 練習メニュー

利用者さんごとに「出す練習」と「難しさ」を決めます。決めた人のアプリには、その練習だけが出て、押すと決めた難しさで すぐ始まります。何も決めていない人には、全部の練習が出ます。

保存すると、その人がアプリを次に開いたとき（施設のタブレットでは、その人を選んだとき）から変わります。QRコードを渡し直す必要はありません。

本人（ご家族）の同意をもらってから オンにしてください。声は施設の Google ドライブの「ことばの練習 録音」フォルダに保存され、このページの「成績」でも聞けます。押すと すぐ変わります。

出す練習に ✓ を入れ、難しさを えらびます。「本人がえらぶ」にすると、いつもどおり えらぶ画面が出ます。同じ練習を ちがう難しさで2つ出すときは［＋］を押します。
✓ を入れると、その人に合わせた 問題数・選択肢の数・お題 と、宿題の回数 も決められます（決めないときは、難しさで決まる いつもの数です）。

利用者を加える

利用者さんのスマホ：その人のQRコードを読み、開いた画面を「ホーム画面に追加」してもらうと、次から1回のタップで始められます。

施設のタブレット：「施設のタブレット用」のQRコードで開いて「ホーム画面に追加」します。はじめに出る「練習する人を えらんで ください」の画面の「職員の方へ」から、利用者番号と名前（タブレットの中だけに保存）を登録してください。30分 何もしないと、次の人が選び直す画面にもどります。

この端末の設定

設定・パスワード・名前のメモは、この端末のブラウザだけに保存されます。スプレッドシートに送られるのは利用者番号と成績だけです。

はじめての準備（1回だけ）

  1. アプリを公開する：アプリは GitHub Pages で公開しています。利用者用アプリは https://greengreen-training.github.io/kotoba-renshu/、このページはその後ろに seiseki.html を付けたものです。アプリを新しくするときは Claude に頼めば、同じURLのまま入れかわります（渡したリンクやQRはそのまま使えます）。
  2. スプレッドシートを作る：施設の Google アカウントで Google ドライブを開き、新しいスプレッドシートを作ります（名前の例：ことばの練習 成績）。
  3. スクリプトを入れる：スプレッドシートのメニュー「拡張機能」→「Apps Script」を開きます。もとからある文字を全部消して、下の［スクリプトをコピー］で写したものを貼り付けます。上のほうの STAFF_PASSWORD の「ここを職員用のパスワードに変える」を、職員だけが知る言葉に書きかえて、保存（💾）します。
  4. ウェブアプリとして公開する：右上の「デプロイ」→「新しいデプロイ」→ 歯車から「ウェブアプリ」を選びます。「次のユーザーとして実行」は自分、「アクセスできるユーザー」は全員にして「デプロイ」。はじめてのときは「アクセスを承認」→ アカウントを選ぶ →「詳細」→「（プロジェクト名）に移動」→「許可」と進みます。
  5. このページに設定する：表示された「ウェブアプリのURL」（最後が /exec）をコピーして、上の「受け取りURL」に貼り、パスワードも入れて［保存して成績を読みこむ］を押します。
  6. 利用者さんに渡す：「利用者のリンク・QR」で利用者番号を入れ、できたQRコードやリンクを渡します。施設のタブレットには「施設のタブレット用」のQRコードを使います。

スクリプトを直したときは、「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョンを「新バージョン」にして「デプロイ」します。「新しいデプロイ」にするとURLが変わり、渡したリンクから成績が届かなくなります。
録音（声）を受け取れるスクリプトにしたあとは、デプロイのときに「アクセスを承認」が出ます。Google ドライブに録音を保存するためなので、同じように「許可」してください。
